# SHIFTREX | 会員・管理者Webアプリ 初期版デモ

**状態: 画面・操作確認用プロトタイプ（本番利用不可）**

フォント設定は `tetotraining/LISTell` の `app/src/style.css` と同一です：`-apple-system, BlinkMacSystemFont, Hiragino Sans, Noto Sans JP, sans-serif`。端末で利用可能なフォントから順に適用されます。LISTell や `100days` のソースは一切変更していません。

SHIFTREX専用、料金不要・外部ライブラリ不要の静的Webアプリです。`shiftrexer` アカウントで将来管理するためのソースです。GitHubリポジトリ `shiftrexer/shiftrex` に保存されています。Cloudflareへの公開は未完了です。

## 含まれる機能（ブラウザー内のデモとして動作）

- 会員側: ホーム、次回の予約、月・週カレンダー、即時確定・承認制の予約申請、申請取消、チケット残数、連絡先変更申請
- 管理者側: ダッシュボード、予約一覧、承認・却下、予約キャンセルとチケット返却選択、予約枠の月公開、枠ごとの承認制切替、会員登録・状態変更、メニュー追加・編集・非表示、購入登録、入金記録、全額入金後のチケット自動発行、チケット期限編集、お知らせ登録
- 購入対象月ONのメニューで年月入力必須。8回券・単発・月会費・食事管理のサンプルメニューあり
- 管理設定に毎日／毎週の自動バックアップ頻度（**設定値の保存のみ**）
- 管理設定からサンプルJSONの手動バックアップ／一括・カテゴリ別復元（関連IDの検証付き）
- 会員・管理者両画面で共通の `localStorage` デモデータを使用（**同じブラウザー、同じドメインのみ共有**）。操作内容はブラウザーごとに異なります。

## 重要な制限

**会員の実名、メールアドレス、電話番号、支払い情報など、現実の個人情報を絶対に入力しないでください。**

現状は認証・権限制御・サーバーDBが存在しません。誰でも管理者画面を開けるため、実際の営業・予約には利用できません。サンプル以外を入れてインターネット公開することは想定していません。

以下は**未実装**です。

- LINE Login、初回招待リンク、自動LINE送信
- 管理者メール・パスワード／2段階認証、オーナー以外のロール管理
- Cloudflare D1等のサーバーデータベースとAPIの共有・同時予約時の排他制御
- 本番プッシュ通知、スケジュール通知、予約リマインダー
- バックエンドの定期自動バックアップ、オーナー認証付きの安全な復元
- 会計の預かり金・返金・購入取消・入金修正、全メニューの例外処理
- 休会の開始日・終了日／自動復帰、退会予約／自動退会、個人情報の適法な削除・匿名化
- 無券予約・チケット処理待ち、詳細な権限設定、会員への通知履歴

画面に見える「DEMO」の表示は、本番認証や自動処理ができていることを意味しません。

## ローカルで試す（無料）

ZIPを展開し、このディレクトリで以下を実行してください。

```bash
python3 -m http.server 8000
```

その後 `http://localhost:8000/` にアクセスします。会員画面は `/member/`、管理者画面は `/admin/` です。セキュリティ制限のあるローカルファイルを直接開く代わりに、HTTPサーバーの利用を推奨します。

## Cloudflare Pagesに無料で置く場合

1. `shiftrexer@gmail.com` のCloudflareアカウントでログインしてください。
2. Pagesの新規プロジェクトを作成し、Direct Upload（直接アップロード）を選択します。
3. 展開したフォルダーの内容をアップロードします（サイトの公開ルートに `index.html` が来るようにしてください）。
4. 発行されたURLの `/member/` と `/admin/` からデモ画面を確認します。
5. **デモを実際の会員向けに使用しないでください。** 公開環境では認証がない状態です。

GitHubで管理したい場合は、`shiftrexer` 側で `shiftrex` などの**新規の専用リポジトリ**を作成し、このファイルをコミットしてからCloudflare Pagesへ接続できます。既存の `shiftrexer/100days` にこのプロジェクトを混ぜないでください。
